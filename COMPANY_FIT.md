# AttackWatch — Company and Team Fit

Potential technical/employer fit only; no company use, endorsement or partnership is implied.

## Project thesis

A command-line tool that reads structured network logs, looks for suspicious patterns and produces alerts grouped by source IP.

## Microsoft

**Relevant public technical areas:** Defender, security engineering and threat intelligence.

**Potential roles:** Security Engineer, Detection Engineer, SOC Automation Engineer, Backend Engineer or Security Research Engineer.

**Evidence to develop:** Python CLI normalises JSON log records, applies configurable detection rules for repeated SSH/RDP events, SQL-injection indicators and port scans, aggregates alerts by source IP and calculates a project-specific risk score. GeoIP and webhook delivery are optional. This is a defensive log-analysis aid, not a replacement for a SIEM or incident response process.
